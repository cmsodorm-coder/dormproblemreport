# 🏢 Dorm Maintenance Ticket Tracker

A web portal built with **Next.js** and **Tailwind CSS** connected directly to **Google Sheets** via **Google Apps Script Web API**.

## 🚀 Setup & Deployment Guide

### 1. Google Apps Script Setup
Ensure your Apps Script project includes the `doGet` function and has been deployed as a **Web App**:
- **Execute as:** `Me`
- **Who has access:** `Anyone`
- Copy the **Web App URL** (`https://script.google.com/macros/s/.../exec`).

### 2. Local Development
```bash
# Clone the repository
git clone [https://github.com/YOUR_USERNAME/dorm-ticket-tracker.git](https://github.com/YOUR_USERNAME/dorm-ticket-tracker.git)
cd dorm-ticket-tracker

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local
# Paste your Apps Script Web App URL into .env.local

# Run development server
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the portal.

### 3. Deploy to Vercel
1. Push your repository to **GitHub**.
2. Go to [vercel.com](https://vercel.com) and click **Add New > Project**.
3. Import this repository.
4. In **Environment Variables**, add:
   - **Key:** `NEXT_PUBLIC_APPS_SCRIPT_API_URL`
   - **Value:** `YOUR_APPS_SCRIPT_WEB_APP_URL`
5. Click **Deploy**.
